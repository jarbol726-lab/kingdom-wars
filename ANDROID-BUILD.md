# Android APK для Kingdom Wars

## Важно

Это приложение использует TanStack Start + Nitro и содержит серверные маршруты. Поэтому его нельзя корректно упаковать как обычный статический сайт. Android-оболочка Capacitor открывает опубликованную HTTPS-версию игры. Для запуска APK требуется интернет и работающий адрес сайта.

## 1. Опубликуйте игру

Разверните проект на Vercel (проект уже содержит `vercel.json`). Убедитесь, что опубликованная ссылка открывает игру в обычном браузере, например `https://your-game.vercel.app`.

## 2. Добавьте адрес в GitHub

В репозитории откройте:

`Settings` → `Secrets and variables` → `Actions` → `Variables` → `New repository variable`

Создайте переменную:

- Name: `APP_URL`
- Value: полный HTTPS-адрес опубликованной игры, например `https://your-game.vercel.app`

Не используйте ссылку предпросмотра Grok — она может быть временной или закрытой.

## 3. Соберите APK

Откройте вкладку `Actions` → `Build Android APK` → `Run workflow`.
После завершения откройте запуск workflow и скачайте artifact `kingdom-wars-debug-apk`. Внутри будет `app-debug.apk`.

Workflow также запускается автоматически при изменении файлов Capacitor или самого workflow в ветке `main`/`master`.

## Ограничения текущей сборки

- Это debug APK для установки и проверки, не подписанный релиз для Google Play.
- Игра загружается с опубликованного сайта, поэтому для неё нужен интернет.
- Если сайт ещё не опубликован или `APP_URL` не задан, сборка намеренно остановится с понятной ошибкой.
